# AI-in-Excel-Assignment-2026

Welcome to my AI in Excel project. This repository documents a hands-on Codebasics Data Analytics Bootcamp 6.0 assignment that explores how AI can clean data, apply business rules, and build summaries directly inside Excel using live formulas, not a separate chat tool. The project turns a movie financials dataset into a verdict-and-ROI-ready table and a language-wise profitability summary with a chart.

## Project Description
This repository documents a hands-on assignment from the Codebasics Excel + AI chapter. Using the AI add-in directly inside Excel, a messy movie financials dataset is cleaned, classified by a Watch Verdict rule, scored by ROI %, and summarized by language, all through live formulas written in a single prompt per phase, not typed-in values.


---

## Folder Structure
- *assignment* - The original assignment brief and a tasks.md tracking the brief's own checklist against what's actually done
- *build-steps* - Phase-by-phase prompts, each step broken out as its own copyable block
- *raw-data* - Meant for the dataset before cleanup; not included here since no untouched copy was preserved before the AI work began
- *result* - The finished workbook with the Watch Verdict, ROI %, and Language Summary sheets
- *prompts* - The exact prompts used, phase by phase, written once and run once



## Key features
- *AI-Written Formulas, Not Typed Values*
- *Automated Data Cleaning*
- *Business Rule Classification (Watch Verdict)*
- *ROI Analysis with Conditional Formatting*
- *Language-wise Profitability Summary & Chart*



## Installation

To explore or modify this Excel project:

1. *Clone the repository:*
   ```bash
   git clone https://github.com/Sachin-Analyst/ai-in-excel-assignment-2026
   ```
   - Open terminal and run the command

2. *Download and Open MS Excel*
   - Any recent version with the ChatGPT or Copilot add-in enabled works

3. *Explore Resources*
     - Open the prompts folder to see the exact prompt behind each formula and rule

4. *Open the Result*
    - Open result/Assignment_Movies_Workbook_final.xlsx to see the finished MovieFinancials, Language Summary, and chart
